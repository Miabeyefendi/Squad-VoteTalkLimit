## 🔭 Обзор
### Что делает

Пока идут голосования за карту и за фракцию после матча, у каждого игрока есть запас времени речи. Речь его тратит, тишина восстанавливает. Когда он пуст, игрок ненадолго заглушается, затем может говорить снова. Когда голосование заканчивается, все размучиваются.

### Как работает

Ruleset на Blueprint (`BP_VoteTalkLimit`, родитель `SQGameRuleSet`) работает на сервере. На каждом тике он читает состояние голосования, хранит одно число на игрока (запас) и решает, кого заглушить. Два варианта отличаются только тем, как мут доходит до игроков:

- `server-only`: сервер вызывает `ToggleMutePlayer` у каждого слушателя.
- `client-rpc`: сервер создаёт `BP_VTLClientHelper`, принадлежащий контроллеру говорящего. Он реплицируется только на этот клиент. На этом клиенте помощник переключает голос при старте и возвращает при завершении. Сервер задаёт его время жизни равным времени мута и уничтожает всех помощников, когда голосование заканчивается.

### Структура файлов

```
src/mod/server-only/VoteTalkLimit/   папка мода варианта server-only
src/mod/client-rpc/VoteTalkLimit/    папка мода варианта client-rpc
src/core/                            генераторы графов (Python)
tests/integration/                   симуляции речи
docs/guides/                         заметки
```

## 🪜 Шаг за шагом
**A. Получите Squad SDK.** Установите Squad SDK (Unreal Editor) и один раз откройте проект `SquadGame`, чтобы он закончил первую загрузку.

**B. Выберите вариант.** Скачайте `VoteTalkLimit-server-only.zip` или `VoteTalkLimit-client-rpc.zip` из [последнего релиза](https://github.com/Miabeyefendi/Squad-VoteTalkLimit/releases/latest). Используйте один за раз.

**C. Скопируйте мод.** Распакуйте в `Squad/Plugins/Mods/` внутри SDK. Получится `Squad/Plugins/Mods/VoteTalkLimit/` с файлом `VoteTalkLimit.mi` и папкой `Content`.

**D. Откройте проект.** Запустите редактор. Откройте Content Browser, при необходимости включите папку содержимого плагинов и найдите `VoteTalkLimit Content`.

**E. Откройте Blueprint.** Дважды щёлкните `BP_VoteTalkLimit`. В варианте `client-rpc` посмотрите также `BP_VTLClientHelper`.

**F. Скомпилируйте.** Нажмите Compile. В строке результата должно быть "successful" без предупреждений. Если нет, см. [Устранение неполадок](#-устранение-неполадок).

**G. Сохраните.** Сохраните все ассеты.

**H. Упакуйте мод.** Используйте команду упаковки модов в SDK для мода `VoteTalkLimit`. Она описана в документации SDK. Результат это собранный мод, который сервер может загрузить.

**I. Загрузите в Workshop.** Загрузите упакованный мод в Steam Workshop как приватный или скрытый элемент, чтобы им пользовался только ваш тестовый сервер.

**J. Добавьте в ModLoader.** На сервере добавьте мод в ModLoader как ruleset так, как описано на странице ModLoader. Сам мод ModLoader уже должен быть на сервере.

**K. Необязательные настройки.** Создайте или отредактируйте `CustomOptions.cfg` в папке конфигурации сервера. См. [Настройки](#️-настройки).

**L. Перезапустите сервер.** Запустите его и проверьте по логу, что мод загрузился.

**M. Клиентская часть (только `client-rpc`).** Игроки, которые заходят, автоматически скачивают мод из Workshop, если сервер его перечисляет. Проверьте на тестовом клиенте, что мод есть.

**N. Найдите второго игрока.** Нужны говорящий и слушающий в одной команде или отряде.

**O. Дойдите до голосования.** Сыграйте матч или промотайте его до конца, чтобы открылось голосование за карту.

**P. Говорите.** Говорящий без пауз повторяет короткий призыв, например «справа сверху справа сверху».

**Q. Слушайте.** Слушающий отмечает, когда голос говорящего обрывается. Говорящий отмечает сообщения на экране.

**R. Дождитесь конца мута.** После времени мута говорящего должно быть слышно снова.

**S. Проверьте конец голосования.** Когда голосование заканчивается, говорящий должен сразу размутиться, даже если время мута не вышло.

**T. Проверьте таблицу результатов.** На экране результатов до голосований никто не должен быть ограничен.

**U. Проверьте выход.** Заглушите говорящего, затем пусть он выйдет с сервера и зайдёт снова. Он не должен быть заглушён.

**V. Запишите результат.** См. [Как читать тест](#-как-читать-тест).

**W. Попробуйте другой вариант.** Уберите мод, установите другой вариант и повторите с шага C.

**X. Подстройте.** Измените `VTL_TalkSeconds` и `VTL_MuteSeconds` по вкусу.

**Y. Сообщите.** Откройте issue с вариантом, тем, что вы услышали, и тем, что увидели на экране.

**Z. Удалите.** Чтобы удалить, уберите мод из ModLoader и удалите папку мода.

## ⚙️ Настройки
| Настройка | По умолчанию | Значение |
|---|---|---|
| `VTL_Enabled` | `true` | Главный выключатель |
| `VTL_TalkSeconds` | `4.0` | Запас времени речи T |
| `VTL_MuteSeconds` | `10.0` | Длина мута M |

Запас восстанавливается со скоростью `T / (T + M)` в секунду. Длинная фраза обрывается через `T * (T + M) / M` секунд: 5,6 при значениях по умолчанию и 4,1 при `T = 3`, `M = 8`. Настройки читаются на лету, поэтому изменение применяется без перекомпиляции.

### Где хранятся настройки

В `CustomOptions.cfg` сервера, они читаются функциями пользовательских серверных настроек SDK. Точный синтаксис файла не проверялся на живом сервере. Если настройка как будто не применяется, используется значение по умолчанию из Blueprint.

## 🧪 Как читать тест
Для каждого варианта запишите:

| Вопрос | Ответ |
|---|---|
| Говорящего оборвало примерно после T секунд речи? | да / нет |
| Слушающий перестал его слышать? | да / нет |
| Заметил ли говорящий, что его заглушили? | да / нет |
| Говорящего снова слышно через M секунд? | да / нет |
| Все ли размутились, когда голосование закончилось? | да / нет |
| Остался ли кто-то заглушённым после выхода и входа? | да / нет |
| Появились ли сообщения на экране? | да / нет |

## 🔧 Устранение неполадок
### Blueprint не компилируется

Откройте панель результатов компилятора. Обычные причины: отсутствует `BP_VTLClientHelper` (скопируйте всю папку `Content`) или другая версия Squad SDK с переименованными пинами.

### Ничего не заглушается

Это наиболее вероятный результат для `server-only`, если функции мута в SDK действуют только на вызвавшем их клиенте. Попробуйте `client-rpc`.

### Сообщения появляются, но голос не обрывается

Ворота и запас работают, не работает только шаг мута. Сообщите с названием варианта.

### Кто-то остаётся заглушённым

Уберите мод из ModLoader и перезапустите сервер, затем сообщите. Этого быть не должно.

## ❓ Вопросы и ответы
**Нужен ли SquadJS?** Нет. В SquadJS нет управления голосом.

**Влияет ли на экран результатов или матч?** Нет, только на голосования после матча.

## 📕 Глоссарий
- **Запас**: оставшиеся секунды речи игрока.
- **Ворота**: условие «идёт голосование», которое включает ограничение.
- **Помощник**: `BP_VTLClientHelper`, маленький актор, который использует вариант `client-rpc`.
- **Ruleset**: класс Blueprint ModLoader на основе `SQGameRuleSet`.
